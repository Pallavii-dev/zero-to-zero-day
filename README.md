# zero-to-zero-day

A structured catalog of **20,000 cybersecurity project ideas** spanning 20 domains — from first-principles security automation all the way to frontier research.

Each section covers 1,000 projects at four skill levels: Beginner → Intermediate → Advanced → Expert → Frontier/Research.

Built as a personal reference and study map across the full attack-defense surface.

## How to use this

Each project entry includes a **title**, **difficulty tag**, a one-line **goal**, and a **suggested stack**. Use it to:

- Pick your next weekend project
- Scope a CTF warmup or practice lab
- Build a learning roadmap by chaining projects across levels
- Find a research gap at the Frontier tier

## Skill levels

| Tag | Description |
|-----|-------------|
| `[Beginner]` | First project in this area; well-documented tools, clear finish line |
| `[Intermediate]` | Requires domain knowledge; involves real CVEs or protocols |
| `[Advanced]` | Multi-system; combines offense + defense; production-grade thinking |
| `[Expert]` | Novel tooling or analysis; publishable quality |
| `[Frontier]` | Open research questions; contributes to the field |
