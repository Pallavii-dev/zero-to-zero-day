# 14. IoT OT and Embedded Systems Security

**Projects:** 1,000  |  **Levels:** Beginner → Intermediate → Advanced → Expert → Frontier / Research
**Catalogue range:** SEC-13001–SEC-14000

Each entry contains one project title and one concise description of what it does. All testing should use owned assets, authorized targets, publicly shareable traces, or isolated simulations. Any attack-related exercise is strictly lab-only and non-destructive.
